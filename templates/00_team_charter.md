## Who owns what
Split the work however suits your team. Every area needs at least one owner.

| Area | Owner(s) |
|---|---|
| Test lead: strategy, plan, priorities, status | |
| Data / SQL tests: ingestion, transformation, storage, consumption | |
| Automation: framework, config, CI, regression pack | |
| AI and governance: AI log, Ops Assistant, generated pack, redaction | |
| Defect management: defects, evidence, retests | |

## Owner lines
Every artifact you write carries a line `Owner: <name>, <OHR>` near the top, and every commit uses your own git
identity. Work with no owner scores for the team but not for any individual.
